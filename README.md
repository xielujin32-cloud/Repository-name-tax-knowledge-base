# 全国税法政策知识库（MVP）

这是一个无第三方依赖、可本地运行的首期实现。它提供：

- 公开、手机优先的知识卡片首页：按税种、业务场景或公式关键词查询；
- 个人所得税工资薪金累计预扣、综合所得年度汇算、经营所得等首批知识卡片；
- 卡片的公式、税率级距、适用条件、示例、生效日期、最后核验时间和官方依据；
- 可添加至手机桌面的 PWA 外壳（政策内容不离线缓存）；
- 官方来源登记与待审候选资料；
- 国家税务总局政策法规库的“立即采集”与每日定时扫描；
- 可暂停、恢复的首次全量导入任务：先建立分类/分页文件清单，再按批次导入待审区；
- 现行/修订/废止/待核验状态及版本关系；
- 成员检索、依据条款定位与“证据不足则拒答”；
- 管理员审核发布、来源维护和审计日志；
- 可替换的问答适配层（默认只基于检索证据生成保守摘要）。

## 运行

```powershell
npm.cmd start
```

打开 `http://localhost:3000`。演示账号：

| 角色 | 用户名 | 密码 |
| --- | --- | --- |
| 成员 | `member` | `member-demo` |
| 管理员 | `admin` | `admin-demo` |

公开首页不需要登录。原有财务工作台仍可通过 `http://localhost:3000/index.html` 打开。

## 知识卡片接口

- `GET /api/knowledge/tax-types`：已发布卡片的税种列表；
- `GET /api/knowledge/cards?query=个人所得税&taxType=个人所得税`：公开搜索；
- `GET /api/knowledge/cards/:id`：已发布卡片详情；
- 管理员使用 `/api/admin/knowledge-card-candidates` 创建待审卡片，并通过 `/:id/review` 审核发布；已发布卡片可通过 `/api/admin/knowledge-cards/:id/rollback` 回退历史版本。

运行时数据保存在 `data/knowledge-base.json`。首次启动时会自动以 `data/seed.json` 初始化；删除运行时数据即可恢复演示数据。

## 安全与生产接入

- 演示登录仅用于本地验证，生产环境应替换为企业统一身份认证，并将会话存储在受控服务中。
- `src/answer.js` 定义了问答适配接口。接入云端模型时，必须仅传入已发布的检索片段，并保留模型调用审计记录。
- 自动采集器不直接发布资料：应通过 `POST /api/admin/candidates` 写入候选队列，由管理员审核。
- 管理员登录后，在“管理工作台”的“国家税务总局政策法规库”点击“立即采集”。系统发现详情页、提取原文和税种建议，并生成待审候选；每日 08:15 也会在服务持续运行时执行一次扫描。
- 如需补齐既有资料，点击同一来源的“全量导入”。任务会先记录可发现的法规详情页清单，再以每批 25 份文件写入待审区；可暂停、恢复，并在服务重启后继续。它不自动发布任何文件。
- 首期采集器仅接入国家税务总局政策法规库。财政部、国务院和人大网站已经登记为来源，但需要分别补充适配器后才能自动采集。

## 部署到 Netlify

公开知识卡片页面可部署到 Netlify；部署配置、环境变量和管理接口说明见 [NETLIFY.md](NETLIFY.md)。Netlify 版本将知识卡片数据保存到 Netlify Blobs，管理员令牌必须在 Netlify 环境变量中配置，不能写进代码。部署依赖可通过 `npm.cmd install` 安装。
